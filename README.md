# Excel Reporter

Excel Reporter is a Python application that automates Excel reporting for business data.

## Features

- Read multiple Excel files automatically
- Clean and validate data
- Calculate business KPIs
- Generate Excel dashboards
- Revenue by Region analysis
- Top Products analysis
- Company logo support
- Automatic report archiving
- Configuration with JSON

## Technologies

- Python
- Pandas
- OpenPyXL
- Loguru
